# 新建一个行程

大约 20 分钟，不需要会编程。要改的只有 `template` 复制出来的那个文件夹里的 3 个文件。

## 第 1 步：复制模板

把 `template` 文件夹整个复制一份，改成你的行程名，例如 `tokyo-2028`
（小写字母、数字、短横线）。

## 第 2 步：改 `index.html`（只改两处）

文件里有 ①②两个注释标出的地方：

- ① `<title>` 里的名字：浏览器标签页上显示的。
- ② `<h1>` 里的大标题。`<i>/</i>` 会变成点缀色的分隔符。

## 第 3 步：改 `trip.js`（基本设置）

每一项文件里都有说明。最少要改：

| 项 | 说明 |
| --- | --- |
| `id` | 英文短名，不能和别的行程重名 |
| `start` | 默认出发日，格式 `2028-04-07` |
| `currency` | 预算用什么币种，`people` 是几个人出行 |
| `wx` | 天气：填几个地点的经纬度和时区。不想要就整段删掉 |

## 第 4 步：改 `content.js`（行程内容）

这是最重要的文件，里面有一份完整的京都示例，把它换成自己的。从上到下分几块：

1. **REG 区域**：给每个地区一个颜色。只去一个城市，就一个区域。
2. **P 地点库**：一行一个地点。写名字、经纬度、一句话说明。
   经纬度怎么查：在 Google 地图上右键点那个地方，第一行就是「纬度, 经度」，直接复制。
3. **V 方案**：每天去哪、几点到哪。只有一个方案就只写 `A`。
4. **BROWS 预算**、**TODOS 待办**：照着示例改。
5. **STAY 住宿方向**、**RULES 要点**：可选，不需要就整段删掉。

### 填错了怎么办

不用担心。如果有填错的地方，页面不会白屏，而是用中文列出来，例如：

> 方案 A 第 2 天第 1 个停靠点引用了地点「fushimi_inari」，但 P 里没有定义它。是不是拼错了？

照着改，保存，刷新就好。

### 最容易出错的三件事

1. 文字里出现了英文单引号 `'`。中文引用用「」，英文缩写别用撇号。
2. 删掉了每一项末尾的逗号。
3. 经纬度写反了（应该是纬度在前）。校验会提醒你。

## 第 5 步：加到首页

打开根目录的 `index.html`，找到 `TRIPS` 那个数组，仿照其中一项加一条：

```js
{href:'./tokyo-2028/', c:'#B3432F', start:'2028-04-07', end:'2028-04-12',
 name:'东京', zh:'五天四晚', when:'4.07 → 4.12', len:'5 天', plans:'1 个方案', key:'樱花季',
 desc:'一两句话介绍。'},
```

## 第 6 步：本地看效果，然后上线

在仓库文件夹里运行 `python -m http.server 8000`，打开 <http://localhost:8000/tokyo-2028/>。
满意了就提交并推送到 GitHub，一两分钟后线上就更新了。

## 进阶：想要自己的特殊部件？

大多数行程不需要。如果想在某个页签里加自己的内容，在 `trip.js` 里写钩子函数：
`planExtra(s)`（方案页）、`prepExtra(s)`（准备页）、`itinHead(s)`（行程页顶部）、
`bookings(v, ids)`（追加预订项）。`trip.js` 里有注释示例。

想改外观：在文件夹里加一个 `trip.css`，在 `index.html` 里取消那行注释，同名样式会覆盖默认值。
想整体换配色，改 `shared/skin.css` 最上面的 `:root`。
