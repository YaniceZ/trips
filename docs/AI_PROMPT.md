# 让 AI 帮你写 `content.js`

下面这段提示词，连同你的行程一起发给 AI（Claude、ChatGPT 都行）。它会输出 `content.js` 和 `trip.js`，
你整段复制进对应文件即可。先把仓库里的 `template/content.js` 和 `template/trip.js` 一并贴给它做参照。

---

## 提示词（整段复制）

```
我要做一个旅行行程网页。请参照我贴出的 template/content.js 和 template/trip.js 的格式，
把下面我的行程整理成这两个文件的内容。

【我的行程】
（在这里贴：去哪、几号到几号、几个人、航班、住宿、每天想去的地方、预算……越具体越好）

【输出要求】
1. 严格沿用模板的数据结构和字段名，不要自创字段。
   REG（区域）、P（用 def() 写地点）、V（方案和每一天）、BROWS、TODOS 必须有。
2. 地点的经纬度必须是你有把握的真实坐标，纬度在前、经度在后。没把握的地点不要编，
   把 p 写成 null，在说明里标注「坐标待补」，并在最后列出来让我自己补。
3. 文字用单引号包住，文字内部不能出现英文单引号，中文引用用「」。每一项末尾保留逗号。
4. 每个停靠点 {t, p, n, s}：t 是时间，p 是地点 id 或 null，n 是名字，s 是补充说明。
5. 不要写任何确认号、订单号、护照号、房间号。这是公开网页。

【请你同时帮我核对（这部分写在回答里，不要写进文件）】
- 以已经出票的航班时间为准排行程。时间对不上就告诉我，整体重排，不要硬塞。
- 每个景点和博物馆的闭馆日、节假日是否冲突（请按我的具体日期算出每天是星期几）。
- 需要提前预约或容易售罄的地方（含热门免费景点），以及大概该提前多久订。
- 一天里的交通和时间是不是太赶。有冲突或风险就直接说，不要顺着我。
- 凡是你不确定的信息（开放时间、票价、政策），明确写「待核实」，不要编。
```

---

## 拿到结果之后

1. 把输出的内容分别放进你复制出来的行程文件夹里的 `content.js` 和 `trip.js`。
2. 刷新页面。如果提示有填错的地方，把提示原文发回给 AI，让它改。
3. **一定要自己核对一遍**：AI 给的坐标、开放时间、票价都可能有错。关键的订票和预约，以官方网站为准。
